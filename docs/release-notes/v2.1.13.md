| --- | --- |
| Windows | `Chat-On-Steroids-Setup-x64.exe` · `Chat-On-Steroids-Setup-arm64.exe` |

The release workflow also builds `Chat-On-Steroids-Extension.zip`, `Chat-On-Steroids-Native-Sources.tar.gz` (corresponding native-library sources and replacement instructions), and `SHA256SUMS.txt`.

macOS builds are publisher-unsigned and unnotarized; macOS 13 Ventura or newer is required. On Linux, prefer the DEB on Debian/Ubuntu; AppImage can fall back to `--no-sandbox` where unprivileged user namespaces are disabled.
